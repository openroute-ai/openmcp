### New Features

This update focuses on enhancing data visualization capabilities to help you better understand and utilize your data:

- **Dashboard Chart Pages**: New data visualization features with intuitive chart displays, helping you quickly understand platform usage
- **Virtual Key Chart Pages**: Dedicated analytics pages for virtual key usage, supporting detailed usage statistics and trend analysis
- **Interaction Improvements**: Enhanced page display and user interaction experience for smoother data browsing

### Improvements & Fixes

- Fixed page display issues to improve interface consistency
- Optimized interaction experience by resolving user-reported operational issues
- Enhanced chart responsive design to ensure excellent display across different devices

### Technical Details

- Integrated modern chart libraries to provide rich data visualization capabilities
- Optimized data query and rendering performance for smooth chart loading
- Improved frontend component maintainability and extensibility
