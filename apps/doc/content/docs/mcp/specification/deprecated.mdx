本页是当前在[特性生命周期与弃用策略](#)
（[SEP-2596](https://github.com/modelcontextprotocol/modelcontextprotocol/pull/2596)）下处于
**已弃用（Deprecated）** 状态的规范特性的注册表。

已弃用特性仍是规范的一部分，但已安排移除计划：新的实现**不应（SHOULD NOT）**采用它，
现有实现**应当（SHOULD）**在该特性的最早移除时间之前进行迁移。最早移除时间
标志着特性可以被移除的_最早_时点；实际移除由核心维护者在发布准备期间
决定，并且可能晚于此时间。

本注册表是一个派生视图，与各特性的
弃用公告和变更日志条目保持一致，后者才是规范性的记录。

## 已移除（Removed）

目前还没有特性在该策略下被移除。当某个已弃用特性
被移除时，其所在行将移入本节，并附上记录该移除的变更日志条目链接。
