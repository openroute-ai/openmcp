## 入门

每个 SDK 都提供相同的功能，但遵循其语言本身的惯用方式与最佳实践。所有 SDK 都支持：

- 创建暴露工具、资源和提示词的 MCP 服务器
- 构建可连接任何 MCP 服务器的 MCP 客户端
- 本地与远程传输协议
- 具备类型安全的协议合规

访问你所选语言的 SDK 页面，查找安装说明、文档和示例。
