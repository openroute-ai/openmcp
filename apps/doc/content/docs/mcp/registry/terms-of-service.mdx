## 概述

本条款（"条款"）管辖您对官方 MCP Registry（托管在 [https://registry.modelcontextprotocol.io/](https://registry.modelcontextprotocol.io/) 或其后续位置的服务，下称"Registry"）的访问和使用，包括对 MCP 服务器的提交或发布、对 MCP 服务器或关于此类服务器及/或其开发者的数据的引用（下称"Registry 数据"）以及相关行为。Registry 旨在成为社区成员开发的 MCP 服务器的集中式仓库，以方便 AI 应用轻松访问。

本条款受加利福尼亚州法律管辖。

## 适用于所有用户

1. 无担保。Registry 按"原样"提供，不附带任何形式的担保。这意味着我们不保证 Registry、Registry 中包含的服务器或 Registry 数据的准确性、完整性、安全性、持久性或可用性。简而言之，我们也不对任何 MCP 服务器或 Registry 数据负责，并且我们强烈建议您在决定是否使用某个 MCP 服务器之前，先评估每个 MCP 服务器及其对您预期使用场景的适用性。

2. 访问和使用要求。要访问或使用 Registry，您必须：
   1. 年满 18 周岁。
   2. 仅以符合美国或其他国家（包括您所在国家，或您访问和使用 Registry 所在的国 家）适用法律的方式使用 Registry、Registry 中的 MCP 服务器和 Registry 数据，并且根据此类法律不被禁止访问或使用 Registry。您将遵守所有适用的法律、法规和第三方权利（包括但不限于有关数据或软件进出口、隐私、知识产权的法律以及当地法律）。您不得使用 Registry、MCP 服务器或 Registry 数据来鼓励或促进非法活动或违反第三方权利或服务条款的行为。
   3. 通过 Registry 维护者认可的方式登录，这可能涉及使用由第三方拥有的应用程序或其他软件。

3. 实体使用。如果您代表某个实体访问或使用 Registry，则您声明并保证您有权让该实体受本条款约束。接受本条款即表示您代表该实体接受（本条款中对"您"的所有引用均指该实体）。

4. 账户信息。为了访问或使用 Registry，您可能需要在注册过程中或与您访问或使用 Registry 或其中的 MCP 服务器相关时提供某些信息（例如身份识别信息或联系详情）。您提供的任何信息都必须准确且最新，并且您同意及时告知我们任何更新。您理解，您的 Registry 使用情况可能会受到监控，以确保质量并验证您遵守本条款。

5. 反馈。您没有义务提供反馈或建议。如果您提供有关 Registry 或模型上下文协议（Model Context Protocol）的反馈或建议，那么我们（以及我们允许的人）可以在不对您承担任何义务的情况下使用这些信息。

6. 品牌使用。仅在明确指代 Registry 时使用"官方 MCP Registry"这一表述，且不得暗示隶属、认可或赞助关系。例如，您可以合理地说"Acme Inc. 通过自动从官方 MCP Registry 拉取数据来保持其数据的时效性"或"此数据来自官方 MCP Registry"，但不能说"这是官方 MCP Registry 的网站"、"我们是查看官方 MCP Registry 数据的首选目的地"或"我们已与官方 MCP Registry 合作提供此数据"。

7. 修改。我们可能会修改本条款或其任何部分，例如为了反映法律的变化或模型上下文协议的变化。我们会在本网站或其后续位置发布本条款修改的通知。如果您不同意修改后的条款，您应停止访问和/或使用 Registry。您继续访问和/或使用 Registry 即构成您接受任何修改后的条款。

8. 附加条款。根据您的预期使用场景，您还必须遵守下文适用的条款。

## 适用于 MCP 开发者

9. 禁止行为。通过访问和使用 Registry，包括提交 MCP 服务器和/或 Registry 数据，您同意不会：
   1. 分享恶意或有害内容，例如恶意软件，即使是出于善意或研究目的，也不得执行任何意在引入任何病毒、蠕虫、缺陷、特洛伊木马、恶意软件或任何具有破坏性质的内容的行为；
   2. 诽谤、辱骂、骚扰、跟踪或威胁他人；
   3. 干扰或破坏 Registry 或任何相关的服务器或网络；
   4. 提交意在迷惑或误导他人的数据，包括但不限于通过垃圾信息、发布与主题无关的营销内容、以虚假暗示与第三方存在隶属或认可关系的方式发布 MCP 服务器，或以不同名称反复发布相同或相似的 MCP 服务器；
   5. 推广或促成非法在线赌博或干扰性的商业消息或广告；
   6. 将 Registry 用于任何可能因使用或故障而导致死亡、人身伤害或环境损害的活动；
   7. 使用 Registry 处理或存储任何受美国国务院管理的《国际武器贸易条例》（International Traffic in Arms Regulations）约束的数据。

10. 许可。您同意，您提交的有关 MCP 服务器的元数据（例如 schema 名称和描述、URL、标识符）以及其他 Registry 数据旨在公开，并将依据 [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/) 奉献给公共领域。通过提交此类数据，您同意您拥有做出此奉献的合法权利（即您拥有这些提交内容的版权，或已获得版权所有者（们）的许可），并有意这样做。您理解此奉献是永久性、不可撤销且全球性的，并且您在法律允许的最大范围内放弃您对自己贡献可能拥有的任何精神权利。此奉献仅适用于 Registry 数据，不适用于您可能指向的第三方注册中心中的软件包。

11. 隐私与公开。您理解，您发布的任何 MCP 服务器元数据都可能被公开。这包括您的 GitHub 用户名、域名或服务器描述中的详细信息等个人数据。此外，您理解其他人可能处理您 MCP 服务器元数据中包含的个人信息。例如，子注册中心可能会通过添加您的 GitHub 仓库获得的星标数量来丰富这些数据，或者对您的代码执行自动安全扫描。通过发布服务器，您同意其他人可以从事此类处理，并且您放弃在部分司法管辖区可能拥有的访问、更正、删除、限制或反对此类处理的权利。
