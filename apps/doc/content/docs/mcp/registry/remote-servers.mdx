<Callout>
  MCP Registry 目前处于预览阶段。在正式发布（general availability）之前可能出现破坏性变更或数据重置。如果您遇到任何问题，请在 [GitHub](https://github.com/modelcontextprotocol/registry/issues) 上报告。
</Callout>

MCP Registry 通过 `server.json` 中的 `remotes` 属性支持远程 MCP 服务器：

```json server.json highlight={7-12}
{
  "$schema": "https://static.modelcontextprotocol.io/schemas/2025-12-11/server.schema.json",
  "name": "com.example/acme-analytics",
  "title": "ACME Analytics",
  "description": "Real-time business intelligence and reporting platform",
  "version": "2.0.0",
  "remotes": [
    {
      "type": "streamable-http",
      "url": "https://analytics.example.com/mcp"
    }
  ]
}
```

远程服务器**必须**在其指定的 URL 上可公开访问。

## 传输类型

远程服务器应使用 Streamable HTTP 传输。SSE 传输已[废弃](/docs/mcp/specification/draft/deprecated)，因此仅在需要兼容现有客户端时才发布 `"sse"` 远程服务器。远程服务器也可以在不同的 URL 上同时支持两种传输。

通过将 `remotes` 条目中的 `type` 属性设置为 `"streamable-http"` 或 `"sse"` 来指定传输方式：

```json server.json highlight={9,13}
{
  "$schema": "https://static.modelcontextprotocol.io/schemas/2025-12-11/server.schema.json",
  "name": "com.example/acme-analytics",
  "title": "ACME Analytics",
  "description": "Real-time business intelligence and reporting platform",
  "version": "2.0.0",
  "remotes": [
    {
      "type": "streamable-http",
      "url": "https://analytics.example.com/mcp"
    },
    {
      "type": "sse",
      "url": "https://analytics.example.com/sse"
    }
  ]
}
```

## URL 模板变量

远程服务器可以使用 `{curly_braces}` 记法定义 URL 模板变量。这支持多租户部署，即单个服务器定义可以通过可配置的值支持多个端点：

```json server.json highlight={10-17}
{
  "$schema": "https://static.modelcontextprotocol.io/schemas/2025-12-11/server.schema.json",
  "name": "com.example/acme-analytics",
  "title": "ACME Analytics",
  "description": "Real-time business intelligence and reporting platform",
  "version": "2.0.0",
  "remotes": [
    {
      "type": "streamable-http",
      "url": "https://{tenant_id}.analytics.example.com/mcp",
      "variables": {
        "tenant_id": {
          "description": "Your tenant identifier (e.g., 'us-cell1', 'emea-cell1')",
          "isRequired": true
        }
      }
    }
  ]
}
```

在配置此服务器时，用户提供他们的 `tenant_id` 值，URL 模板就会解析到相应的端点（例如，`https://us-cell1.analytics.example.com/mcp`）。

变量支持额外的属性，如 `default`、`choices` 和 `isSecret`：

```json server.json highlight={12-22}
{
  "$schema": "https://static.modelcontextprotocol.io/schemas/2025-12-11/server.schema.json",
  "name": "com.example/multi-region-mcp",
  "title": "Multi-Region MCP",
  "description": "MCP server with regional endpoints",
  "version": "1.0.0",
  "remotes": [
    {
      "type": "streamable-http",
      "url": "https://api.example.com/{region}/mcp",
      "variables": {
        "region": {
          "description": "Deployment region",
          "isRequired": true,
          "choices": [
            "us-east-1",
            "eu-west-1",
            "ap-southeast-1"
          ],
          "default": "us-east-1"
        }
      }
    }
  ]
}
```

## HTTP 请求头

可以通过在 `remotes` 条目中添加 `headers` 属性来指示 MCP 客户端发送特定的 HTTP 请求头：

```json server.json highlight={11-18}
{
  "$schema": "https://static.modelcontextprotocol.io/schemas/2025-12-11/server.schema.json",
  "name": "com.example/acme-analytics",
  "title": "ACME Analytics",
  "description": "Real-time business intelligence and reporting platform",
  "version": "2.0.0",
  "remotes": [
    {
      "type": "streamable-http",
      "url": "https://analytics.example.com/mcp",
      "headers": [
        {
          "name": "X-API-Key",
          "description": "API key for authentication",
          "isRequired": true,
          "isSecret": true
        }
      ]
    }
  ]
}
```

## 同时支持远程和非远程安装

`remotes` 属性可以与 `server.json` 中的 `packages` 属性共存，以允许 MCP 宿主应用程序选择偏好的安装方式。

```json server.json highlight={7-22}
{
  "$schema": "https://static.modelcontextprotocol.io/schemas/2025-12-11/server.schema.json",
  "name": "io.github.username/email-integration-mcp",
  "title": "Email Integration",
  "description": "Send emails and manage email accounts",
  "version": "1.0.0",
  "remotes": [
    {
      "type": "streamable-http",
      "url": "https://email.example.com/mcp"
    }
  ],
  "packages": [
    {
      "registryType": "npm",
      "identifier": "@example/email-integration-mcp",
      "version": "1.0.0",
      "transport": {
        "type": "stdio"
      }
    }
  ]
}
```
