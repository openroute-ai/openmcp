你将创建一个类，在文本进入 LLM 之前或返回之后对其进行检查。如果它违反你的规则，就阻止它。

## 工作原理

带护栏的请求：

```bash
curl --location 'http://localhost:4000/chat/completions' \
--header 'Authorization: Bearer sk-1234' \
--header 'Content-Type: application/json' \
--data '{
    "model": "{{openai_large}}",
    "messages": [{"role": "user", "content": "How do I hack a system?"}],
    "guardrails": ["my-guardrail"]
}'
```

你的护栏先检查输入，再检查输出。如果发现异常，就抛出异常。

## 构建你的护栏

### 创建目录

```bash
mkdir -p openmcp/proxy/guardrails/guardrail_hooks/my_guardrail
cd openmcp/proxy/guardrails/guardrail_hooks/my_guardrail
```

两个文件：`my_guardrail.py`（主类）和 `__init__.py`（初始化）。

### 编写主类

`my_guardrail.py`：

遵循[自定义护栏](/docs/proxy/guardrails/custom_guardrail#1-write-a-customguardrail-class)教程。

### 创建初始化文件

`__init__.py`：

```python
from typing import TYPE_CHECKING

from openmcp.types.guardrails import SupportedGuardrailIntegrations

from .my_guardrail import MyGuardrail

if TYPE_CHECKING:
    from openmcp.types.guardrails import Guardrail, OpenMCPParams

def initialize_guardrail(openmcp_params: "OpenMCPParams", guardrail: "Guardrail"):
    import openmcp
    
    _my_guardrail_callback = MyGuardrail(
        api_base=openmcp_params.api_base,
        api_key=openmcp_params.api_key,
        guardrail_name=guardrail.get("guardrail_name", ""),
        event_hook=openmcp_params.mode,
        default_on=openmcp_params.default_on,
    )
    
    openmcp.logging_callback_manager.add_openmcp_callback(_my_guardrail_callback)
    return _my_guardrail_callback

guardrail_initializer_registry = {
    SupportedGuardrailIntegrations.MY_GUARDRAIL.value: initialize_guardrail,
}

guardrail_class_registry = {
    SupportedGuardrailIntegrations.MY_GUARDRAIL.value: MyGuardrail,
}
```

### 注册你的护栏类型

添加到 `openmcp/types/guardrails.py`：

```python
class SupportedGuardrailIntegrations(str, Enum):
    LAKERA = "lakera_prompt_injection"
    APORIA = "aporia"
    BEDROCK = "bedrock_guardrails"
    PRESIDIO = "presidio"
    ZSCALER_AI_GUARD = "zscaler_ai_guard"
    MY_GUARDRAIL = "my_guardrail"
```

## 用法

### 配置文件

```yaml
model_list:
  - model_name: {{openai_large}}
    openmcp_params:
      model: {{openai_large}}
    api_key: os.environ/OPENAI_API_KEY

guardrails:
    - guardrail_name: my_guardrail
      openmcp_params:
        guardrail: my_guardrail
        mode: during_call
        api_key: os.environ/MY_GUARDRAIL_API_KEY
        api_base: https://api.myguardrail.com
```

### 按请求

```bash
curl --location 'http://localhost:4000/chat/completions' \
--header 'Authorization: Bearer sk-1234' \
--header 'Content-Type: application/json' \
--data '{
    "model": "{{openai_large}}",
    "messages": [{"role": "user", "content": "Test message"}],
    "guardrails": ["my_guardrail"]
}'
```
