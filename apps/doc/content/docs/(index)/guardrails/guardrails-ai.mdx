使用 Guardrails AI（[guardrailsai.com](https://www.guardrailsai.com/)）为 LLM 输出添加检查。

## 前置条件

- 设置 Guardrails AI Server。[快速开始](https://www.guardrailsai.com/docs/getting_started/guardrails_server)

## 使用方法

1. 设置 config.yaml

```yaml
model_list:
  - model_name: {{openai_small}}
    openmcp_params:
      model: {{openai_small}}
      api_key: os.environ/OPENAI_API_KEY

guardrails:
  - guardrail_name: "guardrails_ai-guard"
    openmcp_params:
      guardrail: guardrails_ai
      guard_name: "detect-secrets-guard"            # 👈 Guardrail AI guard name
      mode: "pre_call"
      guardrails_ai_api_input_format: "llmOutput"   # 👈 This is the only option that currently works (and it is a default), use it for both pre_call and post_call hooks
      api_base: os.environ/GUARDRAILS_AI_API_BASE   # 👈 Guardrails AI API Base. Defaults to "http://0.0.0.0:8000"
```

2. 启动 OpenMCP 网关

```shell
openmcp --config config.yaml --detailed_debug
```

3. 测试请求

**[Langchain、OpenAI SDK 使用示例](/docs/proxy/user_keys#request-format)**

```shell
curl -i http://localhost:4000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-npnwjPQciVRok5yNZgKmFQ" \
  -d '{
    "model": "{{openai_small}}",
    "messages": [
      {"role": "user", "content": "hi my email is ishaan@berri.ai"}
    ],
    "guardrails": ["guardrails_ai-guard"]
  }'
```

## ✨ 控制每个项目（API Key）运行的护栏

<EnterpriseFeature />

使用此功能控制每个项目运行哪些护栏。在本教程中，我们只希望以下护栏为 1 个项目（API Key）运行
- `guardrails`: ["aporia-pre-guard", "aporia-post-guard"]

**步骤 1** 创建带护栏设置的密钥

<Tabs items={["/key/generate","/key/update"]}>
<Tab>

```shell
curl -X POST 'http://0.0.0.0:4000/key/generate' \
    -H 'Authorization: Bearer sk-1234' \
    -H 'Content-Type: application/json' \
    -d '{
            "guardrails": ["guardrails_ai-guard"]
        }
    }'
```

</Tab>
<Tab>

```shell
curl --location 'http://0.0.0.0:4000/key/update' \
    --header 'Authorization: Bearer sk-1234' \
    --header 'Content-Type: application/json' \
    --data '{
        "key": "sk-jNm1Zar7XfNdZXp49Z1kSQ",
        "guardrails": ["guardrails_ai-guard"]
        }
}'
```

</Tab>
</Tabs>
