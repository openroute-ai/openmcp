使用 [PromptGuard](https://promptguard.co/) 通过提示词注入检测、PII 脱敏、主题过滤、实体阻止列表和幻觉检测保护你的 LLM 应用。PromptGuard 可自托管，并提供即插即用的代理集成。

## 快速开始

### 1. 在 OpenMCP config.yaml 中定义护栏

```yaml showLineNumbers title="config.yaml"
model_list:
  - model_name: {{openai_large}}
    openmcp_params:
      model: openai/{{openai_large}}
      api_key: os.environ/OPENAI_API_KEY

guardrails:
  - guardrail_name: "promptguard-guard"
    openmcp_params:
      guardrail: promptguard
      mode: "pre_call"
      api_key: os.environ/PROMPTGUARD_API_KEY
      api_base: os.environ/PROMPTGUARD_API_BASE   # Optional
```

#### `mode` 支持的值

- `pre_call` – 在 LLM 调用**之前**运行，用于验证**用户输入**
- `post_call` – 在 LLM 调用**之后**运行，用于验证**模型输出**

### 2. 设置环境变量

```shell
export PROMPTGUARD_API_KEY="your-api-key"
export PROMPTGUARD_API_BASE="https://api.promptguard.co"          # Optional, this is the default
export PROMPTGUARD_BLOCK_ON_ERROR="true"                          # Optional, fail-closed by default
```

### 3. 启动 OpenMCP 网关

```shell
openmcp --config config.yaml --detailed_debug
```

## 支持的参数

```yaml
guardrails:
  - guardrail_name: "promptguard-guard"
    openmcp_params:
      guardrail: promptguard
      mode: "pre_call"
      api_key: os.environ/PROMPTGUARD_API_KEY
      api_base: os.environ/PROMPTGUARD_API_BASE       # Optional
      block_on_error: true                             # Optional
      default_on: true                                 # Optional
```

### 必需

| 参数 | 描述 |
|-----------|-------------|
| `api_key` | 你的 PromptGuard API 密钥。回退到 `PROMPTGUARD_API_KEY` 环境变量。 |

### 可选

| 参数 | 默认值 | 描述 |
|-----------|---------|-------------|
| `api_base` | `https://api.promptguard.co` | PromptGuard API 基础 URL。回退到 `PROMPTGUARD_API_BASE` 环境变量。 |
| `block_on_error` | `true` | 默认故障关闭。设置为 `false` 以获得故障开放行为（当 PromptGuard API 不可达时请求通过）。 |
| `default_on` | `false` | 当为 `true` 时，护栏会在每个请求上运行，而无需在请求体中指定它。 |

## 高级配置

### 故障开放模式

默认情况下 PromptGuard 以**故障关闭**模式运行：如果 API 不可达，请求会被拦截。设置 `block_on_error: false` 可在护栏 API 失败时允许请求通过：

```yaml
guardrails:
  - guardrail_name: "promptguard-failopen"
    openmcp_params:
      guardrail: promptguard
      mode: "pre_call"
      api_key: os.environ/PROMPTGUARD_API_KEY
      block_on_error: false
```

### 多护栏

为输入和输出扫描应用不同的配置：

```yaml
guardrails:
  - guardrail_name: "promptguard-input"
    openmcp_params:
      guardrail: promptguard
      mode: "pre_call"
      api_key: os.environ/PROMPTGUARD_API_KEY

  - guardrail_name: "promptguard-output"
    openmcp_params:
      guardrail: promptguard
      mode: "post_call"
      api_key: os.environ/PROMPTGUARD_API_KEY
```

### 始终开启的防护

为每个请求启用护栏，而无需按调用指定：

```yaml
guardrails:
  - guardrail_name: "promptguard-guard"
    openmcp_params:
      guardrail: promptguard
      mode: "pre_call"
      api_key: os.environ/PROMPTGUARD_API_KEY
      default_on: true
```

## 安全功能

PromptGuard 提供针对以下威胁的防护：

### 输入威胁
- **提示词注入** – 检测覆盖系统指令的尝试
- **提示词中的 PII** – 检测并脱敏个人身份信息
- **主题过滤** – 拦截关于禁止主题的对话
- **实体阻止列表** – 阻止引用被阻止的实体

### 输出威胁
- **幻觉检测** – 识别缺乏事实依据的说法
- **PII 泄漏** – 检测并可以脱敏模型输出中的 PII
- **数据外泄** – 防止敏感信息暴露

### 操作

护栏会采取以下三种操作之一：

| 操作 | 行为 |
|--------|-----------|
| `allow` | 请求/响应原样通过 |
| `block` | 请求/响应被拒绝，并附带违规详情 |
| `redact` | 敏感内容被掩码，请求/响应继续 |

## 错误处理

**缺少 API 凭据：**
```
PromptGuardMissingCredentials: PromptGuard API key is required.
Set PROMPTGUARD_API_KEY in the environment or pass api_key in the guardrail config.
```

**API 不可达（故障关闭）：**
请求被拦截，并传播上游错误。

**API 不可达（故障开放）：**
请求原样通过，并记录警告。
