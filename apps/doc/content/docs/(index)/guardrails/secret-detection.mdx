❓ 使用此功能对发送到 LLM 的请求中的 API 密钥、机密进行脱敏。

例如，如果你想在下面的请求中脱敏 `OPENAI_API_KEY` 的值

#### 传入请求 

```json
{
    "messages": [
        {
            "role": "user",
            "content": "Hey, how's it going, API_KEY = 'sk_1234567890abcdef'"
        }
    ]
}
```

#### 处理后的请求

```json
{
    "messages": [
        {
            "role": "user",
            "content": "Hey, how's it going, API_KEY = '[REDACTED]'"
        }
    ]
}
```

**用法**

**第 1 步** 将此添加到你的 config.yaml 文件 

```yaml
guardrails:
  - guardrail_name: "my-custom-name"
    openmcp_params:
      guardrail: "hide-secrets"  # supported values: "aporia", "lakera", .. 
      mode: "pre_call"
```

**第 2 步** 使用 `--detailed_debug` 运行 openmcp 代理以查看服务器日志

```
openmcp --config config.yaml --detailed_debug
```

**第 3 步** 用请求测试

发送此请求
```shell
curl -L -X POST 'http://0.0.0.0:4000/v1/chat/completions' \
-H 'Content-Type: application/json' \
-H 'Authorization: Bearer sk-1234' \
-d '{
    "model": "fake-claude-endpoint",
    "messages": [
      {
        "role": "user",
        "content": "what is the value of my open ai key? openai_api_key=sk-1234998222"
      }
    ],
    "guardrails": ["my-custom-name"]
}'
```

预期会在您的 openmcp 服务器日志中看到以下警告

```shell
OpenMCP Proxy:WARNING: secret_detection.py:88 - Detected and redacted secrets in message: ['Secret Keyword']
```

您还可以使用（`--detailed_debug`）查看从 openmcp 发送到 API 提供商的原始请求。
```text
POST Request Sent from OpenMCP:
curl -X POST \
https://api.groq.com/openai/v1/ \
-H 'Authorization: Bearer gsk_mySVchjY********************************************' \
-d {
  "model": "llama3-8b-8192",
  "messages": [
    {
      "role": "user",
      "content": "what is the time today, openai_api_key=[REDACTED]"
    }
  ],
  "stream": false,
  "extra_body": {}
}
```

## 控制密钥检测器

OpenMCP 使用 [`detect-secrets`](https://github.com/Yelp/detect-secrets) 库进行密钥检测。参见[默认运行的所有插件](#default-config-used)

### 用法

下面介绍如何控制每次请求运行哪些插件。如果开发人员抱怨密钥检测影响响应质量，这会很有用。

**1. 设置 config.yaml**

```yaml
guardrails:
  - guardrail_name: "hide-secrets"
    openmcp_params:
      guardrail: "hide-secrets"  # supported values: "aporia", "lakera"
      mode: "pre_call"
      detect_secrets_config: {
         "plugins_used": [
          {"name": "SoftlayerDetector"},
          {"name": "StripeDetector"},
          {"name": "NpmDetector"}
        ]
      }
```

**2. 启动代理**

使用 `--detailed_debug` 运行以获得更详细的日志。仅用于开发环境。 

```bash
openmcp --config /path/to/config.yaml --detailed_debug
```

**3. 测试它！**

```bash
curl -L -X POST 'http://0.0.0.0:4000/v1/chat/completions' \
-H 'Content-Type: application/json' \
-H 'Authorization: Bearer sk-1234' \
-d '{
    "model": "fake-claude-endpoint",
    "messages": [
      {
        "role": "user",
        "content": "what is the value of my open ai key? openai_api_key=sk-1234998222"
      }
    ],
    "guardrails": ["hide-secrets"]
}'
```

**预期日志**

在您的日志中查找此内容，以确认您的更改按预期生效。

```
No secrets detected on input.
```
