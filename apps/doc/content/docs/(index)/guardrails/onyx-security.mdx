## 快速开始

### 1. 创建一个新的 Onyx Guard 策略

前往 [Onyx 平台](https://app.onyx.security) 并创建一个新的 AI Guard 策略。
创建策略后，复制生成的 API 密钥。

### 2. 在 OpenMCP config.yaml 中定义护栏

在 `guardrails` 部分下定义你的护栏：

```yaml showLineNumbers title="openmcp config.yaml"
model_list:
  - model_name: {{openai_small}}
    openmcp_params:
      model: openai/{{openai_small}}
      api_key: os.environ/OPENAI_API_KEY

guardrails:
  - guardrail_name: "onyx-ai-guard"
    openmcp_params:
      guardrail: onyx
      mode: ["pre_call", "post_call", "during_call"] # Run at multiple stages
      default_on: true
      api_base: os.environ/ONYX_API_BASE
      api_key: os.environ/ONYX_API_KEY
```

#### `mode` 支持的值

- `pre_call` 在 LLM 调用**之前**运行，作用于**输入**
- `post_call` 在 LLM 调用**之后**运行，作用于**输入和输出**
- `during_call` 在 LLM 调用**期间**运行，作用于**输入**。与 `pre_call` 相同，但与 LLM 调用并行运行。在护栏检查完成之前不返回响应

### 3. 启动 OpenMCP 网关

```shell
openmcp --config config.yaml --detailed_debug
```

## 支持的参数

```yaml
guardrails:
  - guardrail_name: "onyx-ai-guard"
    openmcp_params:
      guardrail: onyx
      mode: ["pre_call", "post_call", "during_call"] # Run at multiple stages
      api_key: os.environ/ONYX_API_KEY
      api_base: os.environ/ONYX_API_BASE
      timeout: 10.0 # Optional, defaults to 10 seconds
```

### 必需参数

- **`api_key`**：你的 Onyx Security API 密钥（在 YAML 配置中设置为 `os.environ/ONYX_API_KEY`）

### 可选参数

- **`api_base`**：Onyx API 基础 URL（默认为 `https://ai-guard.onyx.security`）
- **`timeout`**：请求超时（秒）（默认为 `10.0`）

## 环境变量

你可以设置这些环境变量，而不是在配置中硬编码值：

```shell
export ONYX_API_KEY="your-api-key-here"
export ONYX_API_BASE="https://ai-guard.onyx.security"   # Optional
export ONYX_TIMEOUT=10                                  # Optional, timeout in seconds
```
