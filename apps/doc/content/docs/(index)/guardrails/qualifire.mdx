使用 [Qualifire](https://qualifire.ai) 评估 LLM 输出的质量、安全性和可靠性。检测提示词注入、幻觉、PII、有害内容，并验证你的 AI 是否遵循指令。

## 快速开始

### 1. 在 OpenMCP config.yaml 中定义护栏

在 `guardrails` 部分下定义你的护栏：

```yaml showLineNumbers title="openmcp config.yaml"
model_list:
  - model_name: {{openai_small}}
    openmcp_params:
      model: openai/{{openai_small}}
      api_key: os.environ/OPENAI_API_KEY

guardrails:
  - guardrail_name: "qualifire-guard"
    openmcp_params:
      guardrail: qualifire
      mode: "during_call"
      api_key: os.environ/QUALIFIRE_API_KEY
      prompt_injections: true
  - guardrail_name: "qualifire-pre-guard"
    openmcp_params:
      guardrail: qualifire
      mode: "pre_call"
      api_key: os.environ/QUALIFIRE_API_KEY
      prompt_injections: true
      pii_check: true
  - guardrail_name: "qualifire-post-guard"
    openmcp_params:
      guardrail: qualifire
      mode: "post_call"
      api_key: os.environ/QUALIFIRE_API_KEY
      hallucinations_check: true
      grounding_check: true
  - guardrail_name: "qualifire-monitor"
    openmcp_params:
      guardrail: qualifire
      mode: "pre_call"
      on_flagged: "monitor" # Log violations but don't block
      api_key: os.environ/QUALIFIRE_API_KEY
      prompt_injections: true
```

#### `mode` 支持的值

- `pre_call` 在 LLM 调用**之前**运行，作用于**输入**
- `post_call` 在 LLM 调用**之后**运行，作用于**输入和输出**
- `during_call` 在 LLM 调用**期间**运行，作用于**输入**。与 `pre_call` 相同，但与 LLM 调用并行运行。在护栏检查完成之前不返回响应

### 2. 启动 OpenMCP 网关

```shell
openmcp --config config.yaml --detailed_debug
```

## 使用预配置的评估

你可以通过指定 `evaluation_id` 来使用 [Qualifire Dashboard](https://app.qualifire.ai) 中预配置的评估：

```yaml showLineNumbers title="openmcp config.yaml"
guardrails:
  - guardrail_name: "qualifire-eval"
    openmcp_params:
      guardrail: qualifire
      mode: "during_call"
      api_key: os.environ/QUALIFIRE_API_KEY
      evaluation_id: eval_abc123 # Your evaluation ID from Qualifire dashboard
```

当提供 `evaluation_id` 时，OpenMCP 将使用 invoke evaluation API 端点而不是 evaluate 端点，运行你仪表板中预配置的评估。

## 可用的检查

Qualifire 支持以下评估检查：

| 检查                  | 参数                            | 描述                                               |
| ---------------------- | ------------------------------------ | --------------------------------------------------------- |
| 提示词注入      | `prompt_injections: true`            | 识别提示词注入尝试                        |
| 幻觉         | `hallucinations_check: true`         | 检测事实不准确或幻觉             |
| 依据性              | `grounding_check: true`              | 验证输出是否基于提供的上下文             |
| PII 检测          | `pii_check: true`                    | 检测个人身份信息                |
| 内容审核     | `content_moderation_check: true`     | 检查有害内容（骚扰、仇恨言论等） |
| 工具选择质量 | `tool_selection_quality_check: true` | 评估工具/函数调用的质量                   |
| 自定义断言      | `assertions: [...]`                  | 用于验证输出的自定义断言          |

### 多检查示例

```yaml
guardrails:
  - guardrail_name: "qualifire-comprehensive"
    openmcp_params:
      guardrail: qualifire
      mode: "post_call"
      api_key: os.environ/QUALIFIRE_API_KEY
      prompt_injections: true
      hallucinations_check: true
      grounding_check: true
      pii_check: true
      content_moderation_check: true
```

### 自定义断言示例

```yaml
guardrails:
  - guardrail_name: "qualifire-assertions"
    openmcp_params:
      guardrail: qualifire
      mode: "post_call"
      api_key: os.environ/QUALIFIRE_API_KEY
      assertions:
        - "The output must be in valid JSON format"
        - "The response must not contain any URLs"
        - "The answer must be under 100 words"
```

## 支持的参数

```yaml
guardrails:
  - guardrail_name: "qualifire-guard"
    openmcp_params:
      guardrail: qualifire
      mode: "during_call"
      api_key: os.environ/QUALIFIRE_API_KEY
      api_base: os.environ/QUALIFIRE_BASE_URL # optional
      ### OPTIONAL ###
      # evaluation_id: "eval_abc123"  # Pre-configured evaluation ID
      # prompt_injections: true  # Default if no evaluation_id and no other checks
      # hallucinations_check: true
      # grounding_check: true
      # pii_check: true
      # content_moderation_check: true
      # tool_selection_quality_check: true
      # assertions: ["assertion 1", "assertion 2"]
      # on_flagged: "block"  # "block" or "monitor"
```

### 参数参考

| 参数                      | 类型        | 默认值                      | 描述                                              |
| ------------------------------ | ----------- | ---------------------------- | -------------------------------------------------------- |
| `api_key`                      | `str`       | `QUALIFIRE_API_KEY` 环境变量  | 你的 Qualifire API 密钥                                   |
| `api_base`                     | `str`       | `https://proxy.qualifire.ai` | 自定义 API 基础 URL（可选）                           |
| `evaluation_id`                | `str`       | `None`                       | 来自 Qualifire 仪表板的预配置评估 ID    |
| `prompt_injections`            | `bool`      | `true`（如果没有其他检查）  | 启用提示词注入检测                        |
| `hallucinations_check`         | `bool`      | `None`                       | 启用幻觉检测                           |
| `grounding_check`              | `bool`      | `None`                       | 启用依据性验证                            |
| `pii_check`                    | `bool`      | `None`                       | 启用 PII 检测                                     |
| `content_moderation_check`     | `bool`      | `None`                       | 启用内容审核                                |
| `tool_selection_quality_check` | `bool`      | `None`                       | 启用工具选择质量检查                      |
| `assertions`                   | `List[str]` | `None`                       | 用于验证的自定义断言                            |
| `on_flagged`                   | `str`       | `"block"`                    | 内容被标记时的操作：`"block"` 或 `"monitor"` |

### 默认行为

- 如果未提供 `evaluation_id` 且未显式启用任何检查，`prompt_injections` 默认为 `true`
- 当提供 `evaluation_id` 时，它优先，单个检查标志会被忽略
- 当检测到违规时，`on_flagged: "block"` 会抛出 HTTP 400 异常
- `on_flagged: "monitor"` 记录违规但允许请求继续

## 工具调用支持

Qualifire 支持评估工具/函数调用。使用 `tool_selection_quality_check` 时，护栏会分析助手消息中的工具调用：

```yaml
guardrails:
  - guardrail_name: "qualifire-tools"
    openmcp_params:
      guardrail: qualifire
      mode: "post_call"
      api_key: os.environ/QUALIFIRE_API_KEY
      tool_selection_quality_check: true
```

这会评估 LLM 是否选择了合适的工具并提供了正确的参数。

## 环境变量

| 变量             | 描述                    |
| -------------------- | ------------------------------ |
| `QUALIFIRE_API_KEY`  | 你的 Qualifire API 密钥         |
| `QUALIFIRE_BASE_URL` | 自定义 API 基础 URL（可选） |
