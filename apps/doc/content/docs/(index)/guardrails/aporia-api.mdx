使用 [Aporia](https://www.aporia.com/) 检测请求中的 PII 和响应中的不当言论（profanity）

## 1. 在 Aporia 上设置护栏

### 创建 Aporia Projects

在 [Aporia](https://guardrails.aporia.com/) 上创建两个 project

1. Pre LLM API Call - 设置你想在 pre LLM API call 阶段运行的所有策略
2. Post LLM API Call - 设置你想在 post LLM API call 阶段运行的所有策略

<img src="/images/docs/guardrails/aporia_projs.png" />

### Pre-Call：检测 PII

将 `PII - Prompt` 添加到你的 Pre LLM API Call project 中

<img src="/images/docs/guardrails/aporia_pre.png" />

### Post-Call：检测响应中的不当言论

将 `Toxicity - Response` 添加到你的 Post LLM API Call project 中

<img src="/images/docs/guardrails/aporia_post.png" />

## 2. 在 OpenMCP config.yaml 中定义护栏

- 在 `guardrails` 部分定义你的护栏
```yaml
model_list:
  - model_name: {{openai_small}}
    openmcp_params:
      model: openai/{{openai_small}}
      api_key: os.environ/OPENAI_API_KEY

guardrails:
  - guardrail_name: "aporia-pre-guard"
    openmcp_params:
      guardrail: aporia  # supported values: "aporia", "lakera"
      mode: "during_call"
      api_key: os.environ/APORIA_API_KEY_1
      api_base: os.environ/APORIA_API_BASE_1
  - guardrail_name: "aporia-post-guard"
    openmcp_params:
      guardrail: aporia  # supported values: "aporia", "lakera"
      mode: "post_call"
      api_key: os.environ/APORIA_API_KEY_2
      api_base: os.environ/APORIA_API_BASE_2
```

### `mode` 支持的取值

- `pre_call` 在 **LLM 调用之前** 运行，作用于**输入**
- `post_call` 在 **LLM 调用之后** 运行，作用于**输入和输出**
- `during_call` 在 **LLM 调用期间** 运行，作用于**输入**，与 `pre_call` 相同，但与 LLM 调用并行运行。护栏检查完成之前不会返回响应

## 3. 启动 OpenMCP 网关

```shell
openmcp --config config.yaml --detailed_debug
```

## 5. ✨ 控制每个项目（API Key）运行的护栏

<EnterpriseFeature />

使用此功能控制每个项目运行哪些护栏。在本教程中，我们只希望以下护栏为 1 个项目（API Key）运行
- `guardrails`: ["aporia-pre-guard", "aporia-post-guard"]

**步骤 1** 创建带护栏设置的密钥

<Tabs items={["/key/generate","/key/update"]}>
<Tab>

```shell
curl -X POST 'http://0.0.0.0:4000/key/generate' \
    -H 'Authorization: Bearer sk-1234' \
    -H 'Content-Type: application/json' \
    -d '{
            "guardrails": ["aporia-pre-guard", "aporia-post-guard"]
        }
    }'
```

</Tab>
<Tab>

```shell
curl --location 'http://0.0.0.0:4000/key/update' \
    --header 'Authorization: Bearer sk-1234' \
    --header 'Content-Type: application/json' \
    --data '{
        "key": "sk-jNm1Zar7XfNdZXp49Z1kSQ",
        "guardrails": ["aporia-pre-guard", "aporia-post-guard"]
        }
}'
```

</Tab>
</Tabs>
