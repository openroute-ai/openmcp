Pangea 护栏使用其 AI Guard 服务中可配置的检测策略（称为 *recipes*）来识别和缓解 AI 应用流量中的风险，包括：

- 提示词注入攻击（有效率超过 99%）
- 50 多种类型的 PII 和敏感内容，支持自定义模式
- 毒性、暴力、自残及其他不良内容
- 恶意链接、IP 和域名
- 100 多种口语，具有允许列表和拒绝列表控制

所有检测都会记录在审计跟踪中，用于分析、归因和事件响应。
你还可以配置 webhook，为特定检测类型触发告警。

## 快速开始

### 1. 配置 Pangea AI Guard 服务

获取 [AI Guard 服务的 API 令牌和基础 URL](https://pangea.cloud/docs/ai-guard/#get-a-free-pangea-account-and-enable-the-ai-guard-service)。

### 2. 将 Pangea 添加到你的 OpenMCP config.yaml

在配置文件的 `guardrails` 部分下定义 Pangea 护栏。

```yaml title="config.yaml"
model_list:
  - model_name: {{openai_large}}
    openmcp_params:
      model: openai/{{openai_small}}
      api_key: os.environ/OPENAI_API_KEY

guardrails:
  - guardrail_name: pangea-ai-guard
    openmcp_params:
      guardrail: pangea
      mode: post_call
      api_key: os.environ/PANGEA_AI_GUARD_TOKEN  # Pangea AI Guard API token
      api_base: "https://ai-guard.aws.us.pangea.cloud"  # Optional - defaults to this value
      pangea_input_recipe: "pangea_prompt_guard"  # Recipe for prompt processing
      pangea_output_recipe: "pangea_llm_response_guard"  # Recipe for response processing
```

### 6. 后续步骤

- 在 [Pangea 集成指南](https://pangea.cloud/docs/integration-options/api-gateways/openmcp) 中查找关于将 Pangea AI Guard 与 OpenMCP 结合使用的更多信息。
- 调整你的 Pangea AI Guard 检测策略以适配你的用例。详情请参阅 [Pangea AI Guard Recipes](https://pangea.cloud/docs/ai-guard/recipes) 文档。
- 通过启用 [AI Guard webhooks](https://pangea.cloud/docs/ai-guard/recipes#add-webhooks-to-detectors) 及时了解 AI 应用中的检测情况。
- 在 AI Guard 不可变的 [Activity Log](https://pangea.cloud/docs/ai-guard/activity-log) 中监控和分析检测事件。
