## 如何使用护栏测试演练场

护栏测试演练场允许你使用示例输入快速测试和比较不同护栏的行为。

### 测试护栏的步骤

1. **导航到护栏部分**
   - 打开 OpenMCP Admin UI
   - 进入 **护栏** 部分

2. **打开测试演练场**
   - 点击页面顶部的 **测试演练场** 标签页

3. **选择要测试的护栏**
   - 勾选你要比较的护栏
   - 你可以选择多个护栏，查看它们各自对相同输入的反应

4. **输入你的内容**
   - 在文本区域中输入或粘贴你的测试输入
   - 可以是提示词、消息或你想要针对护栏验证的任何文本

5. **运行测试**
   - 点击 **测试护栏** 按钮（或按 Enter）

6. **查看结果**
   - 查看每个所选护栏的输出
   - 比较不同护栏如何处理相同的输入
   - 结果将显示输入是通过还是被每个护栏阻止

## 使用场景

这对于评估护栏解决方案的**安全团队**和 **OpenMCP 管理员**来说非常理想。

这为 OpenMCP 用户带来了以下好处：

- **比较护栏响应**：同时在多个提供商（Lakera、Noma AI、Bedrock Guardrails 等）上测试相同的提示词。

- **验证配置**：在部署到生产环境之前，验证你的护栏能否捕获你关心的威胁。
