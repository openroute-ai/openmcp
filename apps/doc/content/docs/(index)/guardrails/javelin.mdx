Javelin 提供 AI 安全和内容审核服务，支持提示词注入检测、信任与安全违规检测以及语言检测。

## 快速开始
### 1. 在 OpenMCP config.yaml 中定义护栏

在 `guardrails` 部分定义你的护栏

```yaml showLineNumbers title="openmcp config.yaml"
model_list:
  - model_name: {{openai_small}}
    openmcp_params:
      model: openai/{{openai_small}}
      api_key: os.environ/OPENAI_API_KEY

guardrails:
  - guardrail_name: "javelin-prompt-injection"
    openmcp_params:
      guardrail: javelin
      mode: "pre_call"
      api_key: os.environ/JAVELIN_API_KEY
      api_base: os.environ/JAVELIN_API_BASE
      guardrail_name: "promptinjectiondetection"
      api_version: "v1"
      metadata:
        request_source: "openmcp-proxy"
      application: "my-app"
  - guardrail_name: "javelin-trust-safety"
    openmcp_params:
      guardrail: javelin
      mode: "pre_call"
      api_key: os.environ/JAVELIN_API_KEY
      api_base: os.environ/JAVELIN_API_BASE
      guardrail_name: "trustsafety"
      api_version: "v1"
  - guardrail_name: "javelin-language-detection"
    openmcp_params:
      guardrail: javelin
      mode: "pre_call"
      api_key: os.environ/JAVELIN_API_KEY
      api_base: os.environ/JAVELIN_API_BASE
      guardrail_name: "lang_detector"
      api_version: "v1"
```

#### `mode` 支持的取值

- `pre_call` 在 **LLM 调用之前** 对**输入**运行
- `post_call` 在 **LLM 调用之后** 对**输入和输出**运行
- `during_call` 在 **LLM 调用期间** 对**输入**运行。与 `pre_call` 相同，但与 LLM 调用并行运行。响应在护栏检查完成前不会返回

### 2. 启动 OpenMCP 网关

```shell
openmcp --config config.yaml --detailed_debug
```

## 支持的护栏类型

### 1. 提示词注入检测（`promptinjectiondetection`）

检测并拦截提示词注入和越狱尝试。

**类别：**
- `prompt_injection`: 检测操纵 AI 系统的尝试
- `jailbreak`: 检测绕过安全措施的尝试

**响应示例：**
```json
{
  "assessments": [
    {
      "promptinjectiondetection": {
        "request_reject": true,
        "results": {
          "categories": {
            "jailbreak": false,
            "prompt_injection": true
          },
          "category_scores": {
            "jailbreak": 0.04,
            "prompt_injection": 0.97
          },
          "reject_prompt": "Unable to complete request, prompt injection/jailbreak detected"
        }
      }
    }
  ]
}
```

### 2. 信任与安全（`trustsafety`）

跨多个类别检测有害内容。

**类别：**
- `violence`: 与暴力相关的内容
- `weapons`: 与武器相关的内容
- `hate_speech`: 仇恨言论和歧视性内容
- `crime`: 犯罪活动相关的内容
- `sexual`: 色情内容
- `profanity`: 粗俗语言

**响应示例：**
```json
{
  "assessments": [
    {
      "trustsafety": {
        "request_reject": true,
        "results": {
          "categories": {
            "violence": true,
            "weapons": true,
            "hate_speech": false,
            "crime": false,
            "sexual": false,
            "profanity": false
          },
          "category_scores": {
            "violence": 0.95,
            "weapons": 0.88,
            "hate_speech": 0.02,
            "crime": 0.03,
            "sexual": 0.01,
            "profanity": 0.01
          },
          "reject_prompt": "Unable to complete request, trust & safety violation detected"
        }
      }
    }
  ]
}
```

### 3. 语言检测（`lang_detector`）

检测输入文本的语言，并可强制执行语言策略。

**响应示例：**
```json
{
  "assessments": [
    {
      "lang_detector": {
        "request_reject": true,
        "results": {
          "lang": "hi",
          "prob": 0.95,
          "reject_prompt": "Unable to complete request, language violation detected"
        }
      }
    }
  ]
}
```

## 支持的参数

```yaml
guardrails:
  - guardrail_name: "javelin-guard"
    openmcp_params:
      guardrail: javelin
      mode: "pre_call"
      api_key: os.environ/JAVELIN_API_KEY
      api_base: os.environ/JAVELIN_API_BASE
      guardrail_name: "promptinjectiondetection"  # or "trustsafety", "lang_detector"
      api_version: "v1"
      ### OPTIONAL ### 
      # metadata: Optional[Dict] = None,
      # config: Optional[Dict] = None,
      # application: Optional[str] = None,
      # default_on: bool = True
```

- `api_base`: (Optional[str]) Javelin API 的基础 URL。默认为 `https://api-dev.javelin.live`
- `api_key`: (str) Javelin 集成的 API 密钥。
- `guardrail_name`: (str) 要使用的护栏类型。支持的取值：`promptinjectiondetection`、`trustsafety`、`lang_detector`
- `api_version`: (Optional[str]) 要使用的 API 版本。默认为 `v1`
- `metadata`: (Optional[Dict]) 元数据标签可以附加到筛选请求上，作为一个可包含任意键值对的对象。
- `config`: (Optional[Dict]) 护栏的配置参数。
- `application`: (Optional[str]) 用于特定策略护栏的应用名称。
- `default_on`: (Optional[bool]) 护栏是否默认启用。默认为 `True`

## 环境变量

设置以下环境变量：

```bash
export JAVELIN_API_KEY="your-javelin-api-key"
export JAVELIN_API_BASE="https://api-dev.javelin.live"  # Optional, defaults to dev environment
```

## 错误处理

当护栏检测到违规时：

1. **最后一条消息的内容**会被替换为相应的拒绝提示语
2. 消息的角色保持不变
3. 请求会带着修改后的消息继续
4. 原始违规会被记录用于监控

**工作原理：**
- Javelin 护栏会检查最后一条消息是否存在违规
- 如果检测到违规（`request_reject: true`），最后一条消息的内容会被替换为拒绝提示语
- 消息结构保持不变，只有内容发生变化

**拒绝提示语：**
可以在 javelin 门户中配置。
- 提示词注入: `"Unable to complete request, prompt injection/jailbreak detected"`
- 信任与安全: `"Unable to complete request, trust & safety violation detected"`
- 语言检测: `"Unable to complete request, language violation detected"`
