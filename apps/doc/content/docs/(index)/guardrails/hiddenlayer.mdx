OpenMCP 内置了对 [HiddenLayer](https://hiddenlayer.com/) 的原生集成。代理会将每个请求/响应发送到 HiddenLayer 的 `/detection/v1/interactions` 端点，以便你能在不安全内容到达你的用户之前将其拦截或脱敏。

## 快速开始

### 1. 创建 HiddenLayer 项目和 API 凭据

**SaaS（`*.hiddenlayer.ai`）**

1. 登录 HiddenLayer 控制台，并创建（或选择）一个启用了策略的项目。
2. 为该项目生成一个 **Client ID** 和 **Client Secret**。
3. 在 OpenMCP 部署中将其导出为环境变量：

```shell
export HIDDENLAYER_CLIENT_ID="hl_client_id"
export HIDDENLAYER_CLIENT_SECRET="hl_client_secret"

# Optional overrides
# export HIDDENLAYER_API_BASE="https://api.eu.hiddenlayer.ai"
# export HL_AUTH_URL="https://auth.hiddenlayer.ai"
```

**自托管的 HiddenLayer**

如果你在本地（on-prem）运行 HiddenLayer，只需暴露端点并设置：

```shell
export HIDDENLAYER_API_BASE="https://hiddenlayer.your-domain.com"
```

### 2. 将 hiddenlayer 护栏添加到 `config.yaml`

```yaml showLineNumbers title="openmcp config.yaml"
model_list:
  - model_name: {{openai_small}}
    openmcp_params:
      model: openai/{{openai_small}}
      api_key: os.environ/OPENAI_API_KEY

guardrails:
  - guardrail_name: "hiddenlayer-guardrails"
    openmcp_params:
      guardrail: hiddenlayer
      mode: ["pre_call", "post_call", "during_call"] # run at multiple stages
      default_on: true
      api_base: os.environ/HIDDENLAYER_API_BASE
      api_id: os.environ/HIDDENLAYER_CLIENT_ID # only needed for SaaS
      api_key: os.environ/HIDDENLAYER_CLIENT_SECRET # only needed for SaaS
```

#### `mode` 支持的取值

- `pre_call` 在 **LLM 调用之前** 对**输入**运行。
- `post_call` 在 **LLM 调用之后** 对**输入和输出**运行。
- `during_call` 在 **LLM 调用期间** 对**输入**运行。OpenMCP 会并行地把请求发送给模型和 HiddenLayer。响应会等待护栏结果后才返回。

### 3. 启动 OpenMCP 网关

```shell
openmcp --config config.yaml --detailed_debug
```

### 4. 测试请求

你可以使用 `hl-project-id`（映射到 HiddenLayer 项目）和 `hl-requester-id`（审计元数据）标记请求。OpenMCP 会将这两个请求头转发给你的检测器。

## 支持的参数

```yaml
guardrails:
  - guardrail_name: "hiddenlayer-input-guard"
    openmcp_params:
      guardrail: hiddenlayer
      mode: ["pre_call", "post_call", "during_call"]
      api_key: os.environ/HIDDENLAYER_CLIENT_SECRET   # optional
      api_base: os.environ/HIDDENLAYER_API_BASE       # optional
      default_on: true
```

### 必填参数

- **`guardrail`**：必须设置为 `hiddenlayer`，这样 OpenMCP 才会加载 HiddenLayer 钩子。

### 可选参数

- **`api_base`**：HiddenLayer REST 端点。默认为 `https://api.hiddenlayer.ai`，如果你有自托管的实例，请将其指向该实例。
- **`auth_url`**：hiddenlayer 的认证 URL。默认为 `https;//auth.hiddenlayer.ai`。
- **`mode`**：控制护栏何时运行（`pre_call`、`post_call`、`during_call`）。
- **`default_on`**：自动将该护栏附加到每个请求，除非客户端选择退出。
- **`hl-project-id` 请求头**：将扫描路由到特定的 HiddenLayer 项目。
- **`hl-requester-id` 请求头**：设置 `metadata.requester_id` 用于审计。
- **`hl-session-id` 请求头**：将相关请求分组到一个会话中，以便在 HiddenLayer 控制台中进行上下文分析和追踪。

## 环境变量

```shell
# SaaS
export HIDDENLAYER_CLIENT_ID="hl_client_id"
export HIDDENLAYER_CLIENT_SECRET="hl_client_secret"

# Shared (SaaS or self-hosted)
export HIDDENLAYER_API_BASE="https://api.hiddenlayer.ai"
```

只设置你需要的变量，自托管安装可以保持 client ID/secret 未设置，只需配置 `HIDDENLAYER_API_BASE`。
