```python title="Python SDK Example" showLineNumbers
"""
Use OpenMCP Proxy MCP Gateway to call MCP tools.

When using OpenMCP Proxy, you can use the same MCP tools across all your LLM providers.
"""
import openai

client = openai.OpenAI(
    api_key="sk-1234", # paste your openmcp proxy api key here
    base_url="http://localhost:4000" # paste your openmcp proxy base url here
)
print("Making API request to Responses API with MCP tools")

response = client.responses.create(
    model="{{openai_large}}",
    input=[
        {
            "role": "user",
            "content": "give me TLDR of what BerriAI/openmcp repo is about",
            "type": "message"
        }
    ],
    tools=[
        {
            "type": "mcp",
            "server_label": "openmcp",
            "server_url": "openmcp_proxy",
            "require_approval": "never"
        }
    ],
    stream=True,
    tool_choice="required"
)

for chunk in response:
    print("response chunk: ", chunk)
```

#### Specifying MCP Tools

You can specify which MCP tools are available by using the `allowed_tools` parameter. This allows you to restrict access to specific tools within an MCP server.

To get the list of allowed tools when using OpenMCP MCP Gateway, you can naigate to the OpenMCP UI on MCP Servers > MCP Tools > Click the Tool > Copy Tool Name.

### Use with Cursor IDE

Use tools directly from Cursor IDE with OpenMCP MCP:

**Setup Instructions:**

1. **Open Cursor Settings**: Use `⇧+⌘+J` (Mac) or `Ctrl+Shift+J` (Windows/Linux)
2. **Navigate to MCP Tools**: Go to the "MCP Tools" tab and click "New MCP Server"
3. **Add Configuration**: Copy and paste the JSON configuration below, then save with `Cmd+S` or `Ctrl+S`

```json title="Basic Cursor MCP Configuration" showLineNumbers
{
  "mcpServers": {
    "OpenMCP": {
      "url": "openmcp_proxy",
      "headers": {
        "x-openmcp-api-key": "Bearer $OPENMCP_API_KEY"
      }
    }
  }
}
```

#### How it works when server_url="openmcp_proxy"

When server_url="openmcp_proxy", OpenMCP bridges non-MCP providers to your MCP tools.

- Tool Discovery: OpenMCP fetches MCP tools and converts them to OpenAI-compatible definitions
- LLM Call: Tools are sent to the LLM with your input; LLM selects which tools to call
- Tool Execution: OpenMCP automatically parses arguments, routes calls to MCP servers, executes tools, and retrieves results
- Response Integration: Tool results are sent back to LLM for final response generation
- Output: Complete response combining LLM reasoning with tool execution results

This enables MCP tool usage with any OpenMCP-supported provider, regardless of native MCP support.

If tool calls are missing from the response or fail, see [Responses and Chat Completions failures](/docs/mcp-gateway/troubleshoot#responsescompletions-with-embedded-mcp-calls) in the troubleshooting runbook.

#### Auto-execution for require_approval: "never"

Setting require_approval: "never" triggers automatic tool execution, returning the final response in a single API call without additional user interaction.
