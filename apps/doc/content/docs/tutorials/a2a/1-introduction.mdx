欢迎来到 Agent2Agent (A2A) Python 快速入门教程！

在本教程中，你将使用 Python SDK 探索一个简单的"回显"A2A 服务端。这将帮助你了解 A2A 服务端的基本概念和核心组件。随后，你还将学习一个更高级的示例，该示例集成了大语言模型 (LLM)。

这篇实践指南将帮助你理解：

- A2A 协议背后的基本概念。
- 如何使用 SDK 为 A2A 开发搭建 Python 环境。
- 智能体技能 (Agent Skills) 和智能体名片 (Agent Card) 如何描述一个智能体。
- A2A 服务端如何处理任务。
- 如何使用客户端与 A2A 服务端交互。
- 流式能力 (Streaming) 和多轮对话 (Multi-Turn) 的工作原理。
- 如何将 LLM 集成到 A2A 智能体中。

完成本教程后，你将对 A2A 智能体有一个全面的理解，并为构建或集成符合 A2A 标准的应用打下坚实基础。

## 教程章节

本教程分为以下几个步骤：

1. **[简介（当前页面）](/docs/tutorials/a2a/1-introduction)**
2. **[配置开发环境](/docs/tutorials/a2a/2-setup)**：准备你的 Python 环境和 A2A SDK。
3. **[智能体技能与智能体名片](/docs/tutorials/a2a/3-agent-skills-and-card)**：定义智能体的能力以及它的自我描述方式。
4. **[智能体执行器](/docs/tutorials/a2a/4-agent-executor)**：了解智能体逻辑是如何实现的。
5. **[启动服务端](/docs/tutorials/a2a/5-start-server)**：运行 Helloworld A2A 服务端。
6. **[与服务端交互](/docs/tutorials/a2a/6-interact-with-server)**：向你的智能体发送请求。
7. **[流式与多轮对话](/docs/tutorials/a2a/7-streaming-and-multiturn)**：通过 LangGraph 示例探索高级功能。
8. **[后续步骤](/docs/tutorials/a2a/8-next-steps)**：探索 A2A 的更多可能性。

让我们开始吧！
