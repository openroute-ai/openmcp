1. 从服务端获取智能体名片。

## 理解客户端代码

让我们看看 `test_client.py` 的关键部分：

1. **获取智能体名片**：

    ```python
    参考：`test_client.py:A2ACardResolver` — 完整源码见 [test_client.py](https://raw.githubusercontent.com/a2aproject/a2a-samples/refs/heads/main/samples/python/agents/helloworld/test_client.py)
    ```

    `A2ACardResolver` 类是一个便捷工具。当调用 `get_agent_card()` 时，它会从服务端的 `/.well-known/agent-card.json` 端点（基于提供的 base URL）获取 `AgentCard`，然后用于初始化客户端。

2. **初始化客户端并发送非流式消息**：

    ```python
    参考：`test_client.py:message_send` — 完整源码见 [test_client.py](https://raw.githubusercontent.com/a2aproject/a2a-samples/refs/heads/main/samples/python/agents/helloworld/test_client.py)
    ```

    - `create_client` 函数根据 `AgentCard` 提供的信息和 `ClientConfig` 创建一个 `Client`。
    - 我们使用 `new_text_message` 辅助函数构造一个 `Message`（传入 `role=Role.ROLE_USER`），然后将其包装在 `SendMessageRequest` 中。
    - 客户端的 `send_message` 方法返回一个异步迭代器，逐个产出来自智能体的最终 `Task` 或 `Message` 响应。在本示例中，返回的是一个 `Task`。

3. **初始化客户端并发送流式消息**：

    ```python
    参考：`test_client.py:message_stream` — 完整源码见 [test_client.py](https://raw.githubusercontent.com/a2aproject/a2a-samples/refs/heads/main/samples/python/agents/helloworld/test_client.py)
    ```

    - 通过 `create_client` 创建一个单独的流式客户端，在其 `ClientConfig` 中设置 `streaming=True`。
    - 我们再次调用 `send_message`，此时它会流式传输事件：循环的每次迭代都会打印出通过网络到达的一个数据块。
    - 循环结束后调用 `await streaming_client.close()` 以释放底层的 HTTP 连接。

## 预期输出

运行 `test_client.py` 时，你将看到以下内容的输出：

- 公开的智能体名片，以格式化摘要显示。
- 非流式响应：一个以 protobuf 文本格式显示的 `task`，包含已完成状态、包含 "Hello, World!" 的生成工件，以及历史记录中智能体的中间状态消息。
- 流式响应：四个数据块——初始 `task`、WORKING 状态的 `status_update`、包含结果的 `artifact_update`，以及 COMPLETED 状态的最终 `status_update`。
- 扩展版智能体名片，以格式化摘要显示（附带额外的 `super_hello_world` 技能）。
